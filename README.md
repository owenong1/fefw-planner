# Fortune's Weave Planner

Fan-made unit database, army builder and RNG checker for *Fire Emblem: Fortune's Weave*. See [PLAN.md](PLAN.md) for the roadmap.

## Develop

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # schema + cross-reference checks on data/*.json
npm run build      # static site in dist/
```

## Data

Game data lives in `data/*.json`, generated by `npm run import` from source pages cached in `.cache/sources/`. Read [data/SOURCES.md](data/SOURCES.md) before editing, and put hand corrections in `data/overrides.json`. Confirmed and unconfirmed game mechanics are tracked in [data/MECHANICS.md](data/MECHANICS.md).

## Growth simulator

The Class Paths and Simulator pages run a class-path simulator that lives in `src/sim/`; [src/sim/README.md](src/sim/README.md) explains how it works and what its numbers mean. It also runs from a terminal:

```sh
npm run sim -- char Sofia          # recommended class path for each role
npm run sim help                   # every command and option
npm run import:paths               # after changing it: regenerate data/classPaths.json
```

## Deploy

Any static host works. `public/_redirects` gives Netlify/Cloudflare Pages the SPA fallback; on other hosts, rewrite unknown paths to `/index.html`.
